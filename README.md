# Veronica Sølund Kirsebom

Data scientist with a PhD in physics from EPFL. I spent eight years in the LHCb collaboration at CERN, working on machine learning, statistical analysis and Python data pipelines for large experimental datasets. I am now looking for my first role in industry, based in Lausanne.

## Why there is little here from CERN

Most of the code I wrote between 2018 and 2026 was developed inside the LHCb collaboration and lives in its internal repositories, so it is not public. The largest piece is an XGBoost model that I designed, trained and validated, which now selects data in the experiment's live processing. It is described in this paper, where I am the contact author:

[Minimising event size, maximising physics: inclusive particle isolation for LHCb's Run 3](https://doi.org/10.1140/epjc/s10052-026-15398-5), Eur. Phys. J. C 86, 241 (2026)

## Public work

[OK Climat](https://github.com/pydata-switzerland/ok-climat): a Python tool that uses LLMs to extract climate subsidy information from Swiss municipal websites. I started the collaboration at a PyData Lausanne hackathon and am the main technical contributor.
